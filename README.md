Sobre o sistema

O programa foi feito em Java para ajudar uma turma a organizar as tarefas de uma feira tecnica. Ele funciona pelo console e permite cadastrar tarefas, consultar as tarefas e marcar uma tarefa como concluida.

Cada tarefa possui codigo, descricao, nome do responsavel, prioridade e situacao. As tarefas comecam como pendentes.

Funcionalidades

- Cadastrar uma tarefa.
- Listar todas as tarefas.
- Buscar uma tarefa pelo codigo.
- Marcar uma tarefa como concluida.
- Listar somente as tarefas pendentes.
- Mostrar a quantidade de tarefas pendentes e concluidas.
- Encerrar o programa pelo menu.

 Limitacoes do sistema

As tarefas ficam armazenadas somente enquanto o programa esta aberto. Ao fechar o programa, os dados sao perdidos. O sistema nao utiliza banco de dados nem arquivos para salvar as tarefas.

Instrucoes para executar

1. Ter o Java JDK instalado no computador.
2. Abrir a pasta do projeto no Visual Studio Code.
3. Abrir a pasta src.
4. Abrir o arquivo Principal.java.
5. Clicar em Run , para executar o programa.
6. O menu aparecera no terminal, onde sera possivel escolher as opcoes digitando os numeros.

O programa funciona pelo console e nao precisa de banco de dados ou internet para funcionar.
